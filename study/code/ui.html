Rules of a table

You will see a table and answer questions about its rules. Each question names some attributes (columns) and asks whether two records that agree on them must also agree on another attribute.

A question is about every valid state of the table, not only about the ten sample rows you see. The rows only show what the values look like. Answer

  • Yes if the rule must always hold,
  • No if two valid records could break it,
  • Don't know if you cannot tell.

You can open the documentation of the table at any time with the links above the questions.

There are at most about 130 questions and at most about 55 minutes of answering. You can stop at any time with the Stop button, without giving a reason.

  Statistics, saved in 2026 from https://www.abs.gov.au/statistics/standards/australian-statistical-geography-standard-asgs-edition-3 ;

- `tpcds_core/links.json`, `ssb_customer/links.json`: links to the official specifications, which are not copied here.
- `fresh3_fec_candidate/`, `fresh3_synthea_claims/`, `fresh3_tpcc_customer/` (the study's relations): `links.json` with links to the
  publishers' documentation (FEC file descriptions, the Synthea CSV File Data Dictionary, the TPC-C specification), which is not copied here.
  The other three folders are the documentation of the demo's tables.

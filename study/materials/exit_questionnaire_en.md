# Exit questionnaire (shown by the web page after the questions)

DRAFT 2026-10-31. The web page (`code/ui.html`) asks exactly these and stores them in the session file.

1. How familiar were you with the domain of this table? (1 = not at all, 5 = very)
2. How tired did you feel at the end? (1 = not at all, 5 = very)
3. How confident are you in your answers overall? (1 = not at all, 5 = very)
4. If you stopped before the end, why? (I did not stop early / I was tired / It took too long / I was no longer sure
   of my answers / Other)
5. Any comments (optional, free text)
